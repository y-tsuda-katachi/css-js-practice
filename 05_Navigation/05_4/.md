<details>
<summary>小ヒント💡</summary>

以下のイベントの時に関数を実行します。

- DOMContentLoaded : HTML文書などがすべて読み込まれたときに関数を実行する
- mouseenter: マウスカーソルが要素の範囲内に入ったときに関数を実行する

</details>

<details>
<summary>中ヒント💡💡</summary>

以下のメソッドを組み合わせて処理を実装します。
- addEventListener() : イベント発生時に関数を実行させる
- querySelector() : 要素の取得
- querySelectorAll() : 全要素の取得
- getBoundingClientRect() : 要素の寸法と、そのビューポートに対する相対位置に関する情報を取得
- foreach() : コレクションに対して繰り返し処理をする

</details>

<details>
<summary>大ヒント💡💡💡</summary>

以下のような流れで処理を実装します。
```JS
// 1. DOMContentLoadedのイベント発生時に実行する関数を定義
// 1-1. headerというIDを持つ要素を取得
// 1-2. magic-lineというクラスを持つ要素を取得
// 1-3. menuクラス下のaタグ要素を全て取得
// 1-4. 引数にaタグ要素一つを受け取る関数を定義
// 1-4-1. 引数の要素から寸法と位置を取得
// 1-4-2. 1-1で取得した要素の寸法と位置を取得
// 1-4-3. 1-4-1で取得した要素のleftから1-4-2で取得した要素のleftを減算し1-2で取得した要素のleft位置を計算
// 1-4-4. 1-4-1で取得した要素のwidthから1-2で取得した要素の幅を計算
// 1-4-5. 1-2で取得した要素のleftに1-4-3で計算した値を設定
// 1-4-6. 1-2で取得した要素のwidthに1-4-4で計算した値を設定
// 1-5. 1-3で取得した要素に繰り返し処理をする
// 1-5-1. 要素にmouseenterイベントが発生したときの処理を追加
// 1-5-1-1. 1-4で定義した関数を実行
// 1-6. 最初に一回だけ1-4で定義した関数に1-3で取得した要素の最初の要素を渡して実行
```

<details>
<summary>解答例</summary>

```JS
document.addEventListener('DOMContentLoaded', () => {
    const header = document.querySelector("#header");
    const magicLine = document.querySelector(".magic-line");
    const menuItems = document.querySelectorAll(".menu a");

    function moveMagicLine(target) {
        const targetRect = target.getBoundingClientRect();
        const headerRect = header.getBoundingClientRect();
        const left = targetRect.left - headerRect.left;
        const width = targetRect.width;

        magicLine.style.left = `${left}px`;
        magicLine.style.width = `${width}px`;
    }

    menuItems.forEach(item => {
        item.addEventListener("mouseenter", () => {
            moveMagicLine(item);
        });
    });

    moveMagicLine(menuItems[0]);
});
```
