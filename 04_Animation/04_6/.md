<details>
<summary>小ヒント💡</summary>

以下のイベントの時に関数を実行します。

- DOMContentLoaded : HTML文書などがすべて読み込まれたときに関数を実行する

<details>
<summary>中ヒント💡💡</summary>

以下のメソッドを組み合わせて処理を実装します。
- addEventListener() : イベント発生時に関数を実行させる
- querySelector() : 要素の取得
- animate() : キーフレームとオプションでアニメーションを再生する
- observe() : 要素の状態を監視する

</details>

<details>
<summary>大ヒント💡💡💡</summary>

以下のような流れで処理を実装します。
```JS
// 1. DOMContentLoadedのイベント発生時に実行する関数を定義
// 1-1. 引数にentriesをとる関数を定義
// 1-1-1. opacityが0→1、translateが200px 0→0になるようにキーフレームを定義
// 1-1-2. entries引数の最初の要素に対しanimate()を600ミリ秒で実行
// 1-2. 1-1で定義した関数を引数にIntersectionObserverインスタンスを生成
// 1-3. #rand-imgというIDで取得したimg要素を引数に、1-2で生成したインスタンスからobserve()を実行
```

</details>

<details>
<summary>解答例</summary>

```JS
document.addEventListener("DOMContentLoaded", () => {
    const showImage = (entries) => {
        const keyframes = {
            opacity: [0, 1],
            translate: ['200px 0', 0],
        };
        entries[0].target.animate(keyframes, 600);
    };
    const imgObserver = new IntersectionObserver(showImage);
    imgObserver.observe(document.querySelector("#rand-img"))
});
```
