<details>
<summary>中ヒント💡💡</summary>

以下のメソッドを組み合わせて処理を実装します。
- addEventListener() : イベント発生時に関数を実行させる
- querySelector() : 要素の取得
- querySelectorAll() : 全要素の取得
- setTimeout() : 指定時間後に関数を実行する
- animate() : キーフレームとオプションでアニメーションを再生する

</details>

<details>
<summary>大ヒント💡💡💡</summary>

以下のような流れで処理を実装します。
```JS
// 1. DOMContentLoadedのイベント発生時に実行する関数を定義
// 1-1. #loading-labelというIDでh1要素を取得
// 1-2. .rand-imgというクラスを持つ全img要素を取得
// 1-3. 3000ミリ秒後に実行される関数を定義
// 1-3-1. 1-1で取得したh1要素のdisplayをnoneに設定
// 1-3-2. for文を定義し1-2で取得したimg要素数分繰り返しを行う
// 1-3-2-1. opacityが0→1になるようにキーフレームを定義
// 1-3-2-2. durationを600、delayを現在のimg要素添え字 * 300、fillをforwardsでオプションを定義
// 1-3-2-3. 現在のimg要素からanimte()を実行
```

</details>

<details>
<summary>解答例</summary>

```JS
document.addEventListener("DOMContentLoaded", () => {
    const loadingLabel = document.querySelector("#loading-label");
    const images = document.querySelectorAll(".rand-img");
    setTimeout(() => {
        loadingLabel.style.display = "none";
        for (let i = 0; i < images.length; i++) {
            const keyframes = {
                opacity: [0, 1],
            };
            const options = {
                duration: 600,
                delay: i * 300,
                fill: "forwards",
            };
            images[i].animate(keyframes, options);
        }
    }, 3000); // 画像が読み込まれるまでの待機時間
});
```
