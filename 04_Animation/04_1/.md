## アニメーション練習問題１

以下のHTML/CSSをみて、実行結果の通りになるようJavaScriptコードを追加してください。

```HTML
<!doctype html>
<html lang="ja">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Animation_1</title>
    <link rel="stylesheet" href="style.css">
    <script src="script.js"></script>
  </head>
  <body>
    <h1 id="header-label">このレシピのポイント</h1>
  </body>
</html>
```

```CSS
body {
    font-family: serif;
    text-align: center;
}
```

<details>
<summary>小ヒント💡</summary>

以下のイベントの時に関数を実行します。

- DOMContentLoaded : HTML文書などがすべて読み込まれたときに関数を実行する

</details>

<details>
<summary>中ヒント💡💡</summary>

以下のメソッドを組み合わせて処理を実装します。
- addEventListener() : イベント発生時に関数を実行させる
- querySelector() : 要素の取得
- animate() : キーフレームとオプションでアニメーションを再生する

</details>

<details>
<summary>大ヒント💡💡💡</summary>

以下のような流れで処理を実装します。
```JS
// 1. DOMContentLoadedのイベント発生時に実行する関数を定義
// 1-1. #header-labelというIDでh1要素を取得
// 1-2. opacityが0から1、translateが0 50pxから0になるようにキーフレームを定義
// 1-3. durationを2000、easingをeaseでオプションを定義
// 1-4. 1-1で取得したh1要素からanimate()を呼び出す
```

</details>

<details>
<summary>解答例</summary>

```JS
document.addEventListener("DOMContentLoaded", () => {
    const headerLabel = document.querySelector("#header-label");
    const keyframes = {
        opacity: [0, 1],
        translate: ['0 50px', 0],
    };
    const options = {
        duration: 2000,
        easing: 'ease',
    };
    headerLabel.animate(keyframes, options);
});
```

</details>
